# 门店督导分布

> 数据源：项目根目录 [`门店分布.xlsx`](../门店分布.xlsx)  
> 系统常量：[`app/src/constants/storeDistribution.ts`](../app/src/constants/storeDistribution.ts)

## 结构说明

| Excel 位置 | 含义 |
|------------|------|
| 左侧（B 列） | **督导片区**，如「杜志灵区」— 负责人为姓名去掉「区」字 |
| 右侧（E 列） | 该督导下辖的**具体门店** |
| 右侧靠后列 | 总部职能（仓库部、市场部等），非门店列表 |

## 与员工档案

已开通门店员工使用 **Excel 标准店名**（与企微部门一致）：

| 门店 | 督导 |
|------|------|
| 中山西区天悦城店 | 杜志灵 |
| 中山坦洲优越城店 | 杜志灵（坦洲属小榄片区地理范围） |

更新 Excel 后请同步修改 `storeDistribution.ts` 并执行 `cd app && npx tsx scripts/exportSeedData.ts` 与 `cd api && python -m scripts.seed --phase 1`。
