# 本地前后端联调指南

## 一键流程

```powershell
# 1. 后端
cd api
copy .env.example .env
pip install -r requirements.txt
python -m scripts.seed --phase all
python -m scripts.sync_public_assets
python -m uvicorn app.main:app --reload --port 8100

# 2. 自检（新终端）
cd api
python -m scripts.verify_connectivity

# 3. 前端
cd app
copy .env.example .env
npm install
npm run dev
```

浏览器打开 http://localhost:3100 ，登录 `KS20250001` / `123456`。

## 环境变量

| 文件 | 关键项 |
|------|--------|
| `app/.env` | `VITE_USE_MOCK=false`，`VITE_API_BASE_URL=http://localhost:8100/api/v1` |
| `api/.env` | `DATABASE_URL=sqlite:///./caisedi_dev.db`（无 Docker）或 PostgreSQL URL |

## 静态资源

图片、PDF 放在 `app/public/stores|news|training/`，执行：

```powershell
cd api
python -m scripts.sync_public_assets
```

API 通过 `http://localhost:8100/assets/...` 访问；中文文件名已自动 URL 编码。

## 纯前端演示（无后端）

`app/.env` 设置 `VITE_USE_MOCK=true`，仅 `npm run dev` 即可。

## 常见问题

| 现象 | 处理 |
|------|------|
| 门店图裂图 | 跑 `sync_public_assets` |
| 文档 PDF 404 | 同上；确认 `storage/training/` 有文件 |
| 列表空白 | 看 CatalogLoader 错误页；确认 API 8100 已启动 |
| 30 分钟后掉线 | 已实现 refresh；仍失败则重新登录 |
